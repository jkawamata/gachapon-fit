# gachapon-fit

48mmガチャポンFIT は、作成したSLTファイルが48mmガチャポンに収まるかをブラウザ上で判定するための Web アプリです。
3Dプリンタで出力する前に、作品の大きさや向きを確認し、必要に応じて倍率を調整した提出用 STL を保存できます。
公開ページはこちらです。

https://jkawamata.github.io/gachapon-fit/


概要

中学校技術科などの授業で、ガチャカプセルに入る作品を設計する際に使うことを想定しています。
生徒が作成した STL ファイルをドラッグ＆ドロップすると、48mm ガチャカプセルの中に収まるかを自動判定します。入らない場合は、どの程度小さくすればよいかを確認したり、自動縮小して再判定したりできます。
また、提出用 STL 保存機能により、学年・クラス・番号・氏名・日時を含むファイル名で STL を保存できます。これにより、提出された STL ファイルの整理や確認がしやすくなります。


主な機能

STL ファイルのドラッグ＆ドロップ読み込み
48mm ガチャカプセルに入るかどうかの自動判定
カプセルの肉厚を考慮した内径判定
判定結果の視覚的表示
STL の回転・拡大縮小表示
倍率スライダーによるサイズ調整
自動縮小と再判定
推奨される回転・位置の表示
提出用 STL ファイルの保存
学年・クラス・番号・氏名をもとにしたファイル名の自動生成
ブラウザだけで動作する Web アプリ


使い方

1. アプリを開く　以下のページをブラウザで開きます。
https://jkawamata.github.io/gachapon-fit/

2. STL ファイルを読み込む
判定したい STL ファイルを画面上にドラッグ＆ドロップします。
または、画面右上の「STLを選ぶ」ボタンからファイルを選択します。

3. 判定結果を確認する
読み込んだ STL が、48mm ガチャカプセルの内部に収まるかどうかを自動で判定します。
入る場合は、その向きや位置が表示されます。
入らない場合は、はみ出し量や縮小の目安を確認できます。

4. 必要に応じて調整する
倍率スライダーを使って STL の大きさを調整できます。
入らない場合は、自動縮小して再判定することもできます。

5. 提出用 STL を保存する
「提出用STL保存」ボタンを押すと、学年・クラス・番号・氏名を入力して、提出用ファイル名で STL を保存できます。
ファイル名には日時も自動で付加されます。

例：
1501_20260626_1030_ガチャポン太郎.stl
この例では、1501 は「1年5組1番」を表します。


授業での活用例

このアプリは、3D CAD で設計した作品を「本当にガチャカプセルに入る形にできているか」を確認するために使えます。
生徒は、単に形を作るだけでなく、次のような視点をもって設計を見直すことができます。

大きさは適切か
向きを変えれば入るのか
どの程度縮小すればよいのか
3Dプリンタで出力した後、実物として成立するか
提出する STL ファイル名が正しく整理されているか

「設計 → 判定 → 修正 → 再判定」という試行錯誤を支援するための教材アプリです。

開発の考え方

このアプリは、授業の中で生まれた必要感をもとに、現場で使いながら改善していくことを重視しています。
授業中に見えてきた困りごとや、生徒のつまずきに合わせて、機能や表示を少しずつ更新していくための教材開発です。
いわば、授業を創るように Web アプリを作る的な実践の一つです。


注意事項

判定結果は、STL データ上の形状をもとにした計算結果です。
実際の3Dプリントでは、プリンタの精度、材料の収縮、サポート材、積層方向などの影響を受ける場合があります。
最終的には、実物のガチャカプセルで確認することをおすすめします。
極端に複雑な STL や、非常に大きな STL は、読み込みや判定に時間がかかることがあります。
